# Couch Cube roadmap

## The goal

Four friends, one Mac, a TV and whatever controllers people bring. Couch party games
(Overcooked, Rocket League, Pummel Party, LEGO Party, Runbow…), Switch party games
(Mario Party) and retro classics should just work on an Apple Silicon Mac such as an
M4 Mac mini — set up in minutes, played entirely with controllers.

Couch Cube should feel like Apple made it: simple, native, obvious to anyone who uses a Mac.

## Principles

- Controllers first: connecting, naming, ordering and testing mixed controllers must be painless.
- Steam Big Picture and ES-DE always stay available as TV menus; Couch Cube's own TV mode is an
  option, never forced.
- Games can live on this Mac or an external SSD and move between Macs (e.g. a 256 GB Mac mini and a
  more powerful MacBook Pro).

## Milestones

1. **Polish what exists** — review every page, fix layout, wording and flows; Console Mode, App
   Settings and Game library: only the essentials, short and friendly, nothing scary;
   Cube Shop: a modern Mac game store (storefront Home, one game row style, game pages); confirm SSD,
   Console Mode and controller hotplug on a real Mac (→ beta).
2. **Couch Cube TV mode** — a full-screen, Apple TV–style home screen driven by controller:
   - one grid of all games: Steam (Mac), Windows games via compatibility layers (CrossOver,
     Steam in a VM…), Epic/GOG/Battle.net, emulator games (incl. Switch);
   - folders/collections (e.g. "Party", "4 players", "Retro");
   - controller management (who is player 1–4, battery, connect/disconnect) without a keyboard,
     as simple as on the Mac window: pairing a new controller works from the TV mode too;
   - button hints use one neutral four-dot diamond with the pressed position filled (like Switch
     icons), never X/□/○/△ or A/B/X/Y, so every brand of controller reads the same;
   - every connected controller can navigate. Start+Select together locks the menu to that
     controller; the same combo unlocks it, and Start+Select on another controller takes over —
     so friends can't mess up the menu while someone is choosing;
   - media tiles: YouTube (TV web app), Apple Music and other apps/web apps, also opened by controller.
3. **Desktop launcher** — the same library in the normal Mac window, so when playing at the desk
   (e.g. Warcraft II through Battle.net on Windows) every game is one click away, wherever it lives.
4. **More consoles** — PlayStation and SEGA cards split into Home consoles / Handhelds like
   Nintendo; add PS Vita (Vita3K) and SEGA Game Gear; PS4 (shadPS4) only once it runs games
   reliably on Apple Silicon (experimental today).
5. **Storage** — external SSD library shared between Macs, with clear status and safe moves.
